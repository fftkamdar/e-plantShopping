# e-plantShopping — Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is a React-based online houseplant shopping application designed to help users explore and shop for indoor plants.

## Features

- Landing page with company information and a Get Started button.
- Houseplants organized into three categories.
- Product cards with images, names, and prices.
- Add to Cart functionality with disabled buttons after adding a product.
- Dynamic shopping cart item count.
- Cart quantity increase and decrease controls.
- Remove products from the shopping cart.
- Automatic calculation of item totals and the overall cart amount.
- Checkout placeholder and Continue Shopping navigation.

## Technologies Used

- React
- Vite
- JavaScript
- Redux Toolkit
- React Redux
- React Router DOM
- CSS

## How to Run the Project

1. Install Node.js and npm.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL displayed in the terminal.

## Project Purpose

This project demonstrates frontend development, component-based architecture, routing, state management, and shopping cart functionality.
